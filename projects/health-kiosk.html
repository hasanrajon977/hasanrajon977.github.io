Self-Service Health Checkup Kiosk

Low-cost, Bengali-language health checkup kiosk concept for local supermarkets in Bangladesh.

Raspberry Pi / ESP32Biomedical sensorsWHO/AHA ranges

Objective

Design a low-cost, self-service kiosk that lets people in Bangladesh check basic health indicators at local supermarkets, with an interface in Bengali.

Key features

  • Controller: Raspberry Pi / ESP32
  • Sensors for blood pressure, heart rate, SpO2, ECG, temperature and BMI
  • Rule-based result analysis against WHO/AHA reference ranges
  • Bengali-language user interface

Approach & decisions

How the work progressed, stage by stage.

  1. Define the user and setting: everyday shoppers, minimal supervision, low cost.
  2. Choose the controller and sensor set to cover the six measurements.
  3. Map each reading to WHO/AHA reference ranges to produce a simple rule-based result.
  4. Present the result in Bengali so it is understandable to the general public.
